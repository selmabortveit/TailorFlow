TAILORFLOW - RUN INSTRUCTIONS FOR THE TUTOR

Main script: app.py
Python required: 3.10 or newer.

1. Keep the entire TailorFlow_Web folder together.
2. Open a terminal in that folder.
3. Run: python3 app.py
   On Windows, the command may be: python app.py
4. Open http://127.0.0.1:5001 in a browser on the same laptop.
5. Leave the terminal running. Stop with Ctrl+C when finished.

This is a local Python web application using Flask and bundled dependencies in libraries.zip. Run it outside Ed’s preview; no pip installation is required.

I used ChatGPT to help debug the Python application, improve its design, and create the logo.

GitHub link: https://github.com/selmabortveit/TailorFlow
